📊 FINANCIAL TRACKING
═════════════════════════════════════════════════════════════════════════

AUTOMATIC CALCULATIONS
- Total Collected = Sum of all participant amounts
- Total Spent = Sum of (product price × quantity)
- Balance = Total Collected - Total Spent
- Average = Total Collected ÷ Number of Participants
- Paid Count = Participants with amount ≥ ৳400

⚠️ COMMON QUESTIONS
═════════════════════════════════════════════════════════════════════════

Q: Forgot access code?
A: Default is: AFTABx7766

Q: Lost data?
A: Check Settings > Access Codes to verify auth works
   Check if localStorage is enabled in browser

Q: Can I use on multiple devices?
A: Not automatically. You need to backup/restore manually.

Q: Is my data safe?
A: Completely safe. All data is local, never sent anywhere.

Q: Can I add more than 1000 entries?
A: Yes! localStorage can handle 5-10MB (years of data).

Q: How do I delete everything?
A: Go to browser > Settings > Clear cache/localStorage

Q: Does it work offline?
A: Yes! Works perfectly without internet.

Q: Can I export the data?
A: Yes! Use the export functionality in the app.


🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════

LOGIN NOT WORKING
1. Check if code is correct (case-sensitive)
2. Make sure Caps Lock is off
3. Try clearing browser cache
4. Reload the page

DATA NOT SAVING
1. Check if localStorage is enabled
2. Try a different browser
3. Clear cache and retry
4. Check browser storage settings

THEME NOT CHANGING
1. Refresh the page
2. Clear cache
3. Check browser history
4. Hard refresh (Ctrl+Shift+R)

SLOW PERFORMANCE
1. Clear browser cache
2. Disable extensions
3. Try incognito mode
4. Use latest browser version
